# Tarea JavaFX - Navegación y Reutilización de Formularios

## Integrante
- Nombre: Alisson Quiguango
- Materia: Programación Orientada a Objetos

## Descripción

Este proyecto fue desarrollado en JavaFX utilizando Scene Builder para la creación de interfaces gráficas. La aplicación permite la navegación entre formularios según el rol seleccionado y la realización de una encuesta con calificación automática.

## Funcionalidades

### Práctica 1: Navegación entre formularios
- Inicio de sesión mediante Login.
- Selección de rol (Administrador o Cajero).
- Navegación al formulario correspondiente.
- Validación de campos.
- Cierre del formulario Login al ingresar correctamente.

### Práctica 2: Formulario principal
- Configuración de Administrador.fxml como pantalla principal.
- Inicio directo de la aplicación sin pasar por el Login.

### Práctica 3: Encuesta
- Encuesta de 4 preguntas.
- Cálculo automático de respuestas correctas.
- Cálculo automático de respuestas incorrectas.
- Visualización del puntaje total obtenido.
